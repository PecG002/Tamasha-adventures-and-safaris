# Tamasha-adventures-and-safaris
Tourism &amp; Travel website 
Tamasha Adventure & Safaris Website
Files
index.html — the main website
style.css — colours, layout and responsive design
script.js — website behaviour
content.js — business and trip information
edit.html — simple browser-based editor
assets/ — the supplied Tamasha logo and trip posters
Easiest way to edit
Open edit.html in a browser.
Change the business/trip details.
Click Save on this device to preview changes on that device.
Click Download content.js if you want a permanent file containing the new information.
Replace the old content.js in the website folder with the downloaded one.
Put it online
This is a static website, so it can be hosted on services such as GitHub Pages, Netlify or Vercel. Upload the entire folder, keeping the assets folder in the same location.
Editing the design
Open style.css in any code editor. The main brand colours are green, orange/yellow, white and dark charcoal. The site is responsive for phones and computers.
Important
The browser editor uses localStorage. It is an editing convenience, not a shared online CMS. For changes to appear for every visitor, replace content.js on the hosted website and redeploy/upload it.
