# Tamasha Adventure & Safaris v2

Pages: Home, About Us, Events, Private Guide, Contact, Edit.

Upload all files to GitHub Pages and keep the assets folder beside the HTML files. The home page uses a cinematic hero made from the supplied trip imagery. The Private Guide page supports one-on-one/custom journeys and the Contact form opens WhatsApp with the visitor's trip details.

To edit text/events, open edit.html. For site-wide changes, export content.js and replace the repository copy.
